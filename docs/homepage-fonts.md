# 首页字体设置

管理员可在 Nexus 管理设置选择柳体、黑体、宋体或楷体。当前选择通过原子替换的 /data/nexus-settings.json 持久化，不修改账户数据库或其 schema；登录用户可读取，只有管理员能更新。API 仅接受 homeFont 固定枚举，拒绝额外字段和 CSS/font URL。

字体选择只作用于首页卡片、首页展示标题与内嵌任务标题。任务正文、时间数据、完整管理页和认证界面保持已有字体。柳体使用项目已有的本地 WOFF2；黑体、宋体、楷体使用简体中文系统字体栈，实际可用字体取决于访问者的设备。没有选项会向外部请求字体文件。旧镜像会忽略新增的设置文件，因此保留原数据卷即可回滚应用镜像。
