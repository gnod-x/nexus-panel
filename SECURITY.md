# Security Policy

Please report vulnerabilities privately to the repository maintainer. Do not include passwords, session cookies, private service URLs, or personal data in public issues.

Supported versions are the latest tagged release and the current default branch. Security fixes are developed and released from a private report where practical.

Nexus Panel can make HTTP requests to configured targets. Restrict access to operators who are trusted to add health-check destinations, keep the default loopback binding, and place remotely accessible deployments behind an authenticated private network or identity-aware proxy.
